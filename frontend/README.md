# FixDesk

FixDesk is a responsive IT support portal interface for **“Find Solutions. Fix Issues. Get Support.”**

## Run locally

```bash
npm install
npm run dev
```

The current frontend is self-contained and uses local demo data, so it can be presented without database credentials or an external service.

## Included in the demo

- Responsive FixDesk workspace shell with role-oriented navigation
- Searchable and category-filterable knowledge base
- Popular search suggestions and article empty state
- Ticket activity dashboard with status and priority indicators
- Create-ticket modal with validation and local ticket updates
- Notification popover and toast feedback
- Mobile navigation drawer and responsive layouts
